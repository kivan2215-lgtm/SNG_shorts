Русская звуковая правка для выпуска Pepsi. Целевые формы: вле́зет, поло́жите (будущее время), ко́нчился, начала́сь, носки́, у па́рня, сочла́.
Слоговая длительность, тон, энергия и спектр изменены только в семи окнах исходной дорожки. Для ориентира использованы фразы Silero v4_ru с заданным ударением; границы слогов оценены по bond005/wav2vec2-base-ru. Длительность исходного монтажа сохранена. Контроль по разности дорожек обнаружил семь окон. Полный MP4 декодирован, инструментальная проверка не заменяет проверку ударений на слух.
