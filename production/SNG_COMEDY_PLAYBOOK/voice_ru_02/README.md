Проба 02 для русской комедийной ветки. Ожидает прослушивания пользователем. Базовая дорожка V4. В render() применяется сохранённый preset.npz, рассчитанный по параллельным начальным фразам. Вход моно 24 кГц, float64. Зависимости numpy, scipy, pyworld. Запускать из каталога пресета. В этой версии длительности меняются, поэтому при монтаже нужно заново привязать субтитры, звук и сцены к словам. Проба содержит фразы с 40,04 по 48,515 секунды исходной дорожки. Оригинальная запись Telegram в поставку не входит.
