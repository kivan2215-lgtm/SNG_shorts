# Комедийный рассказчик 01
Пробная русская озвучка по референсу от 19 ноября 2026 года. База ru-RU-DmitryNeural, скорость +2%, связные абзацы, прежние настройки пауз V4. После сборки монофонической речи применить render.py к WAV (Python, praat-parselmouth, numpy), затем добавить музыку. Пробы записаны с целевой медианой 185 Гц, коэффициентом формант 1.12 и диапазона тона 0.89. Длительность слогов сохраняется. В образце пользователя медиана определённого основного тона около 236 Гц.
 
Перед синтезом раскрывать числа и проверять ударение по контексту. Для этого сценария ориентиры: договори́ться, едини́цы, измере́ния, нью́тон-секу́нды, траекто́рии. В следующих выпусках сначала сверять имена, омографы и новые термины; изменение регистра само по себе не исправляет ошибку в исходном произношении. Проба ожидает оценки пользователя.
