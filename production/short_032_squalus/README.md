# SNG 032 — Squalus

Самостоятельный пробный выпуск на русском и английском, 1080×1920, 30 fps. Применяет обновлённые правила от 14 ноября 2026. Создан для просмотра пользователем; не утверждён и не загружен на YouTube.

## Сборка

Python 3.12, ffmpeg с libass/libx264, DejaVu Sans. Пакеты: Pillow, numpy, scipy, edge-tts==7.2.3; requests и beautifulsoup4 для исследования.

1. Прочитать ../SNG_SHORTS_PLAYBOOK/README.md (в публикационной копии путь может отличаться), SOURCES.md и shot_plan.json.
2. Озвучка: `python voice.py ru` и `python voice.py en`; затем `python pace.py`. Не запускать pace.py на уже сокращённом файле без сохранённых исходников; скрипт использует voice_uncut.wav.
3. Сборка: `python build.py ru` и `python build.py en`. Режим `--stills` создаёт план кадров без фильма.
4. Проверка: `python qc.py`. Слуховая проверка указана отдельно и не заменяется ffprobe.

Один проект обслуживает обе версии; тайминги вычисляются отдельно по записанным словам каждого языка. Готовые MP4 выдаются отдельно, без ZIP. Названия и описания находятся в metadata.json и приводятся в сообщении пользователю.

## V2 — моделированная объёмная графика

Первая плоская графика отклонена пользователем. V2 заменяет её авторскими 3-D сценами Blender: подлодка в разрезе, вода в кормовых отсеках, дверь переборки, водолаз с тросом, камера Маккэнна и переход по лестнице. Цветные выноски привязаны к деталям; раскрытие идёт по действиям диктора. V2 остаётся preview для просмотра.

Зависимость: Blender 4.3.2 (Workbench, native 1080×1920). 

1. `python v2/render_all.py` — модели и нормализованные последовательности кадров для обеих языковых версий. Статичная геометрия кэшируется; интерактивное состояние/выноски анимирует compositor. После изменения модели удалить соответствующий каталог `v2/frames/<scene>` перед повторным рендером.
2. `python build_v2.py ru` и `python build_v2.py en` — прежние mix.wav, timeline.json и subtitles.ass, новая графика. Голос и скорость не меняются.
3. `python qc_v2.py` — полный декод, технические параметры, громкость, чёрные кадры, контактные листы из итогового MP4.

Шкала глубины показывает 74 м / 243 ft, но взаимные масштабы камеры/судна/лодки увеличены для читаемости. Количество условных фигур внутри не воспроизводит состав конкретного рейса. Схема не представляет точного исторического инженерного чертежа.

## V3 — реалистичнее материалы, люди и движение

Направление V2 положительно оценено пользователем; V3 дорабатывает реализм и плавность. Все 19 типов 3D сцен получают новый свет и материалы; люди используют анатомический скелет вместо сборных примитивов. Подробности и источники CC0 в `v3/PLAN.md`, `SOURCES.md` и `v3/human/LICENSE.md`.

1. Blender 4.3.2 с Eevee; переменная `BLENDER` указывает путь исполняемого файла. `python v3/render_all.py` создаёт сцены и последовательности. При изменении исходника удалить кэш соответствующей сцены из `v3/frames` и `v3/raw_frames`; не смешивать версии.
2. `python build_v3.py ru` / `python build_v3.py en` создают отдельные MP4 1080×1920, 30 fps с прежней озвучкой.
3. `python qc_v3.py` проверяет итоговые файлы. Поля визуальной и слуховой проверки независимы; технический декод не равен прослушиванию.

Исходный PBR-рендер 720×1280, итоговые подписи и субтитры — 1080×1920. Движущиеся механизмы интерполируются с 15 до 30 fps; сцена подъёма человека по лестнице рендерится в 30 fps. Сохранённые Blender-сцены показывают одно состояние; исходный Python воспроизводит движение.

## V4 — свет, материалы и опора движений

`v4/scene3d.py`, `human_model.py`, `render_style.py` — моделирование и Cycles CPU.
`v4/region_cache.py` — кэш неподвижной области после полноэкранных проб; движущаяся геометрия и её тени рассчитываются в 30 fps. Оптическая интерполяция кадров не применяется. Крупный план уплотнения намеренно изолирует механизм от фигур людей.
`visuals_v4.py` — RU/EN выноски; `build_v4.py` — сборка с копированием AAC V3 без пересинтеза; `qc_v4.py` — техническая проверка и кадры из экспортов.

Запуск: `python v4/render_all.py`, затем `python build_v4.py ru`, `python build_v4.py en`, `python qc_v4.py`, `python v4/check_preservation.py`. Требуются Blender 4.3.2, FFmpeg, Python с Pillow/NumPy/requests. Путь к Blender задаётся переменной BLENDER. Пути Python в region-cache runner соответствуют текущей студии; при переносе заменить на локальный интерпретатор с Pillow/NumPy.

Исходные кадры моделей 720×1280; конечная композиция и надписи 1080×1920. V4 — полный preview на двух языках для просмотра, не утверждённый финал.
