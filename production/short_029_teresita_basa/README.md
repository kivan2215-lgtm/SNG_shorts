# SNG Shorts 029 — Teresita Basa

Review cuts: `ru/SNG_029_Teresita_Basa_RU_PREVIEW.mp4` and `en/SNG_029_Teresita_Basa_EN_PREVIEW.mp4`.

Format: 1080×1920, 30 fps, H.264 video, AAC stereo audio. Both cuts use the same chronology and separate natural language narration and word aligned subtitles. The opening preserves the mystery; the final section distinguishes the Chuas' account from the independently recovered jewelry. Illustrative scenes are used for moments without archival imagery. `SOURCES.md` records provenance; `QC.json` records media checks.

Source files: `narration.txt`, `voice.wav`, `words.json`, `captions.json`, `timeline.json`, and scene stills in each language folder; `build.py` and `visuals.py` for reproducibility. Production follows `production/SNG_SHORTS_PLAYBOOK/00_MASTER_SETTINGS.md` in the publication repository.
