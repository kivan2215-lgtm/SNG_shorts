# «Васа» / Vasa
Русская озвучка опирается на одобренную пробу 04. Каждый из пяти абзацев синтезируется целиком с одним и тем же голосовым образцом; температура 0.72. Короткая пауза между абзацами 125 мс. Для русской и английской дорожек тайминг пересчитывается отдельно. Черновая автоматическая расшифровка используется для синхронизации с оригинальным сценарием. Исторические персонажи в живописных сценах — иллюстрации. Исходные музейные фотографии перечислены в SOURCES.md. Проверка воспроизведения программная, проверка кадров по выборке. Полное прослушивание не выполнено.
