# Постоянная рабочая папка SNG Shorts

Эта папка — основной источник настроек для следующих выпусков. Она заменяет старые разрозненные заметки в `production/PRODUCTION_PREFERENCES.md`, где есть устаревшие настройки отдельных роликов. Перед каждым выпуском читать все файлы этой папки и сценарий текущего ролика. После конкретного замечания пользователя обновлять соответствующее правило здесь.

- [Формат и монтаж](01_FORMAT_AND_EDIT.md)
- [Сценарий, факты и архивы](02_STORY_AND_SOURCES.md)
- [Озвучка, субтитры и звук](03_VOICE_AND_SOUND.md)
- [Схемы и визуализация](04_DIAGRAMS_AND_VISUALS.md)
- [Сборка, проверка и отправка](05_WORKFLOW_AND_DELIVERY.md)
- [Что уже исправляли](06_LESSONS_BY_EPISODE.md)

Приоритет: текущая просьба пользователя → эти постоянные предпочтения → сценарий конкретного выпуска → технические шаблоны. Если сценарий спорит с подтверждённым фактом, исправить фактическую ошибку и отметить это в источниках.
