# Сборка, проверка и отправка

1. Прочитать эту папку и сценарий. Проверить ключевые факты и сформировать список кадров с источниками.
2. Подготовить сценарий под естественную длительность. Озвучить целиком, убрать излишние паузы; обновить субтитры по финальной дорожке.
3. Собрать вертикальные кадры и схемы; просмотреть первый кадр, лица, объекты, схему и финал в натуральном разрешении. Не допускать повторов, обрезок и пустых экранов.
4. Свести музыку ниже голоса. Проверить соответствие сцены словам, титров звуку, отсутствие чёрных кадров и ошибок MP4. Выполнить полный декод ролика `ffmpeg -v error -i FILE.mp4 -f null -`; проверить разрешение, FPS, длительность, кодеки. Проверку на слух не подменять технической проверкой.
5. Сначала создавать preview для просмотра. После одобрения — отдельные YouTube/TikTok final версии из того же проекта, без водяных знаков; не называть preview финальным.
6. Пользователь предпочитает **прямую ссылку на один MP4**, без ZIP и боковой панели. Публикация в публичном `kivan2215-lgtm/SNG_shorts` ранее разрешена. Выдавать `https://raw.githubusercontent.com/kivan2215-lgtm/SNG_shorts/main/<имя>.mp4` после успешного push. Сохранять рядом `SOURCES.md`.
7. YouTube не подключён к автоматической загрузке; пользователь загружает вручную. При запросе давать название и описание с хэштегами, не обещая попадания в рекомендации.

Для каждого нового выпуска создавать отдельный каталог проекта: `narration.txt`, проект сборки, `SOURCES.md`, preview, замечания пользователя и статус. Хранить только проверенные факты и явные предпочтения. При новой правке обновлять эту папку и ссылку на актуальную версию.
