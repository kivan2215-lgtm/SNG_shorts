# Олимпийский марафон 1904 года

Готовые самостоятельные монтажи RU и EN лежат в корне репозитория. Тексты для публикации — в PUBLICATION.md. Источники и авторство архивных кадров — в SOURCES.md.

Для повторного монтажа из этой папки запустить `python edit.py ru` и `python edit.py en`. Нужны FFmpeg с libass и libx264, Pillow, NumPy, SciPy и системный шрифт DejaVu. В папке сохранены утверждаемые звуковые дубли, тайминги слов, архивы и листы постановочных изображений. Повторный синтез голоса для рендера не требуется.

План кадров в edit.py привязан к словам, а не к общей секундной сетке. art.py рисует отдельно для каждой языковой версии маршрут и сравнение двух поездок через финишную черту. Постановочные изображения и авторская графика дополняют шесть архивных материалов. В описании у фотографии Хикса важны слова «после финиша».
