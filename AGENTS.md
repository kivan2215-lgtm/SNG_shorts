# SNG Shorts: рабочая инструкция

Перед работой над новым роликом или правкой прочитай [папку правил](production/SNG_SHORTS_PLAYBOOK/README.md). Она содержит постоянные предпочтения пользователя, процесс производства и историю правок. Новые подтверждённые требования добавляй туда же; устаревшие инструкции явно заменяй, чтобы они не конфликтовали.

Для выдачи пользователю публикуй конкретный MP4 в этом репозитории и давай прямую ссылку `https://raw.githubusercontent.com/kivan2215-lgtm/SNG_shorts/main/<файл>.mp4`. Не называй предварительную версию финальной и не утверждай, что звук прослушан, если доступна только техническая проверка.
